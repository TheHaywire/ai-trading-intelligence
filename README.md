A comprehensive trading intelligence platform that combines technical analysis, machine learning, and real-time AI insights to provide actionable trading decisions.

## ✨ Key Features

### 🤖 AI-Powered Analysis
- **Google Gemini 2.0 Integration** - Real-time AI verdicts with confidence scores
- **News Sentiment Analysis** - Via Finnhub API for market context
- **ML Predictions** - Random Forest & Gradient Boosting models
- **Trade Quality Scoring** - 100-point systematic evaluation

### 📊 Multi-Timeframe Intelligence
- **4 Timeframe Analysis** - M15, H1, H4, D1 simultaneously
- **Trend Alignment Detection** - Identify fully aligned markets
- **Historical Context** - 7-day and 30-day performance tracking
- **Support/Resistance Levels** - Automatic calculation

### 🎯 Symbol Decision Cards
- **Individual Analysis Per Symbol** - Detailed cards for each asset
- **Clear Trade Decisions** - BUY/SELL/HOLD with reasoning
- **Entry/Stop/Target Prices** - Precise levels calculated
- **Risk Warnings** - AI-identified potential issues
- **Beautiful HTML Reports** - Professional-grade visualization
