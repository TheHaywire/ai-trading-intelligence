===============================================================================
                      TRADING SYSTEM - QUICK REFERENCE
===============================================================================

All commands use: python trade.py <command>

-------------------------------------------------------------------------------
BASIC COMMANDS
-------------------------------------------------------------------------------

status              Show account status, positions, P&L
scan                Scan markets and execute trades
diagnostic          Run full health check
market              Get market overview
close-losers        Close all losing positions
close-all           Close ALL positions (asks confirmation)
gold-analysis       Analyze Gold reversal probability
ai-analysis         Deep AI analysis of all positions
help                Show all commands

-------------------------------------------------------------------------------
EXAMPLES
-------------------------------------------------------------------------------

Check account status:
  python trade.py status

Scan and trade:
  python trade.py scan

Run diagnostic:
  python trade.py diagnostic

Close losers:
  python trade.py close-losers

SETTINGS (core/config.py)
-------------------------------------------------------------------------------
