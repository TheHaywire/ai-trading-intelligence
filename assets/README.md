# Assets Folder - Screenshots & Demos

This folder contains visual assets for the repository README.

## Required Screenshots

Please add the following screenshots to make the repository look professional:

### 1. **symbol_cards_demo.png**
Screenshot of the main Symbol Cards HTML report showing:
- Header with "SYMBOL DECISION CARDS" title
- At least 2-3 symbol cards visible
- Shows the complete card structure:
  - Symbol name and current price
  - Multi-timeframe analysis section
  - Historical performance (7d/30d)
  - AI Intelligence section with verdict
  - Trade setup with entry/stop/target
  - Clear decision (BUY/SELL/DON'T TRADE)
  - Detailed reasoning

**How to capture:**
1. Run `python trade.py cards`
2. Take full-page screenshot of the HTML report
3. Save as `symbol_cards_demo.png`

### 2. **mtf_alignment_demo.png**
Close-up screenshot of the Multi-Timeframe Analysis section showing:
- M15, H1, H4, D1 timeframes
- Trend indicators for each
- RSI values
- MACD signals
- Overall alignment status (e.g., "FULLY ALIGNED BULLISH")

**How to capture:**
1. Open generated symbol cards report
2. Zoom in on the multi-timeframe section of any card
3. Capture clear screenshot
4. Save as `mtf_alignment_demo.png`

### 3. **ai_intelligence_demo.png**
Close-up of the AI Intelligence section showing:
- AI Verdict (BUY/SELL/HOLD)
- Confidence percentage
- Key reasoning text
- Risk factor text
- Latest news headline

**How to capture:**
1. Open generated symbol cards report
2. Zoom in on AI Intelligence section
3. Capture clear screenshot
4. Save as `ai_intelligence_demo.png`
