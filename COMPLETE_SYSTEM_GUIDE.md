## ⚙️ Configuration (If You Want to Customize)

### Change Alert Thresholds:

Edit `real_time_signal_alerts.py` (line 23-29):

```python
ALERT_THRESHOLDS = {
    'min_confidence': 75,      # Default: 75% (change to 70 or 80)
    'min_price_move': 2.0,     # Default: 2% (change to 1.5 or 3.0)
    'min_signal_score': 8,     # Default: 8 (change to 6 or 10)
    'breakout_lookback': 50,   # Default: 50 periods
    'volume_spike': 2.0,       # Default: 2x (change to 1.5x or 3x)
}
```
